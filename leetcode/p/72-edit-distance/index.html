class Solution {
    public int minDistance(String word1, String word2) {
        int m = word1.length();
        int n = word2.length();
        int[][] dp = new int[m+1][n+1];
        char[] c1 = word1.toCharArray();
        char[] c2 = word2.toCharArray();

        for (int i = 1; i <= m; i++) dp[i][0] = i;
        for (int j = 1; j <= n; j++) dp[0][j] = j;

        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (c1[i-1] == c2[j-1]) {
                    dp[i][j] = dp[i-1][j-1];
                } else {
                    dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1;
                }
            }
        }
        return dp[m][n];
    }

    private int min(int a, int b, int c) {
        return Math.min(a, Math.min(b, c));
    }

}

  • Why did I choose this particular implementation?
    • 视频图解 动态规划 编辑距离
    • bottom-up解法
    • 定義狀態：
      • dp[i][j]表示word1中前i個字符，轉變到word2中前j個字符，最短需要操作的次數
    • base case：
      • 第一行，是 word1 為空，變成 word2 最少步数，就是插入操作
      • 第一列，是 word2 为空，需要的最少步数，就是删除操作
    • 狀態轉移方程：
      • 如果 word1[i] == word2[j]
        • dp[i][j] = dp[i-1][j-1]
      • 如果 word1[i] != word2[j]
        • insert: dp[i][j-1]
        • delete: dp[i-1][j]
        • replace: dp[i-1][j-1]
