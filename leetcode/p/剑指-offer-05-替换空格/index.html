Question

请实现一个函数，把字符串 s 中的每个空格替换成"%20"。

✍🏽 My Solution

class Solution {
    public String replaceSpace(String s) {
        int n = s.length();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            if (s.charAt(i) == ' ') {
                sb.append('%');
                sb.append('2');
                sb.append('0');
            }
            else {
                sb.append(s.charAt(i));
            }
        }
        return sb.toString();
    }
}

Solution #1 [王爭-不使用Java提供的ArrayList和StringBuilder]

class Solution {
    // 不使用Java提供的ArrayList和StringBuilder
    public String replaceSpace(String s) {
        int n = s.length();
        // 统计有多个空格
        int spaceCount = 0;
        for (int i = 0; i < n; ++i) {
            if (s.charAt(i) == ' ') {
                spaceCount++;
            }
        }
        // 计算新数组⻓度
        int newLen = n + spaceCount * 2;
        char[] newStr = new char[newLen];
        int j = newLen - 1;
        for (int i = n-1; i >= 0; --i) {
            char c = s.charAt(i);
            if (c != ' ') {
                newStr[j] = c;
                j--; 
            } else {
                newStr[j] = '0';
                newStr[j-1] = '2';
                newStr[j-2] = '%';
                j-=3;
            }
        }
        return new String(newStr);
    }
}
