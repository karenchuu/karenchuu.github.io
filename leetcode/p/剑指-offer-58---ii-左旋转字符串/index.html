剑指 Offer 58 - II. 左旋转字符串

在 LeetCode 開啟 ↗Open on LeetCode ↗
Question

字符串的左旋转操作是把字符串前面的若干个字符转移到字符串的尾部。请定义一个函数实现字符串左旋转操作的功能。比如，输入字符串"abcdefg"和数字2，该函数将返回左旋转两位得到的结果"cdefgab"。

示例 1：

输入: s = "abcdefg", k = 2
输出:"cdefgab"

示例 2：

输入: s = "lrloseumgh", k = 6
输出:"umghlrlose"

限制：

  • 1 <= k < s.length <= 10000

✍🏽 My Solution

class Solution {
    public String reverseLeftWords(String s, int n) {
        // 開立一個n空間
        char[] k = new char[n];
        char[] str = s.toCharArray();
        int len = s.length();
        // 把前面n個字符拷貝過去
        for (int i = 0; i < n; i++) {
            k[i] = str[i];
        }
        // 原數組往前搬移
        for (int i = n; i < len; i++) {
            str[i-n] = str[i];
        }
        // 把新開的數組拷貝到原數組最後面
        for (int i = 0; i < n; i++) {
            str[len-2+1] = k[i];
        }
        return new String(str);
    }
}
