Solution #1 [一一映射數組]

// 思路：
// 1. 猜中：位置猜中 顏色猜中
//    偽猜中：位置沒猜中 顏色猜中
// 2. 先計算猜中的，再計算偽猜中
// 3. solution猜中過的就不能再匹配了
class Solution {
    public int[] masterMind(String solution, String guess) {
        int n = solution.length();
        boolean[] used = new boolean[n]; // guess哪些被用過了

        // 猜中
        int hitCount = 0;
        for (int i = 0; i < n; i++) {
            if (solution.charAt(i) == guess.charAt(i)) {
                used[i] = true;
                hitCount++;
            }
        }

        // 偽猜中
        int fakeHitCount = 0;
        for (int i = 0; i < n; i++) {
            if (solution.charAt(i) == guess.charAt(i)) continue;
            for (int j = 0; j < n; j++) {
                if (solution.charAt(i) == guess.charAt(j) && !used[j]) {
                    used[j] = true;
                    fakeHitCount++;
                    break;
                }
            }
        }
        return new int[]{hitCount, fakeHitCount};
    }
}

  • How does their solution work?
    • 猜中：位置猜中 顏色猜中
    • 偽猜中：位置沒猜中 顏色猜中
    • 先計算猜中的，再計算偽猜中
    • solution猜中過的就不能再匹配了
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(n)
