class Solution {
    public int multiply(int A, int B) {
        if (A == 1) return B;
        int halfValue = multiply(A/2, B);
        if (A % 2 == 1) {
            return halfValue + halfValue + B;
        } else {
            return halfValue + halfValue;
        }
    }
}

  • How does their solution work?
    • A/2 * B + A/2 * B 奇數
    • A/2 * B + A/2 * B + B 偶數

    • f(A,B) = f(A/2 * B) + f(A/2 * B) + B 奇數
