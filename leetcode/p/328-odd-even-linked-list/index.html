328. Odd Even Linked List

考過的公司：Bytedance、tiktok
在 LeetCode 開啟 ↗
Question

Given the head of a singly linked list, group all the nodes with odd indices together followed by the nodes with even indices, and return the reordered list.

The first node is considered odd, and the second node is even, and so on.

Note that the relative order inside both the even and odd groups should remain as it was in the input.

You must solve the problem in O(1) extra space complexity and O(n) time complexity.

Example 1:

Input: head = [1,2,3,4,5]
Output: [1,3,5,2,4]

Example 2:

Input: head = [2,1,3,5,6,4,7]
Output: [2,3,6,7,1,5,4]

Constraints:

  • n == number of nodes in the linked list
  • 0 <= n <= 10^4
  • 10^6 <= Node.val <= 10^6

✍🏽 My Solution

Solution #1 [technique]

class Solution {
    public ListNode oddEvenList(ListNode head) {
        if (head == null) return head;
        ListNode evenHead = head.next;
        ListNode even = evenHead;
        ListNode odd = head;
        while (even != null && even.next != null) {
            odd.next = even.next;
            odd = odd.next;
            even.next = odd.next;
            even = even.next;
        }
        odd.next = evenHead;
        return head;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 創建odd跟even指針
    • 創建even頭節點
    • 將head頭節點串上所有的奇數節點
    • 將even頭節點串上所有的偶數節點
    • 將even鏈表合併進head鏈表
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(1)

Solution #2 [王爭-創建奇數及偶數結果鏈表]

class Solution {
  public ListNode oddEvenList(ListNode head) {
            if (head == null) return null;
            ListNode oddHead = new ListNode();
            ListNode oddTail = oddHead;
            ListNode evenHead = new ListNode();
            ListNode evenTail = evenHead;
            ListNode p = head;
            int count = 1;
            while (p != null) {
                    ListNode tmp = p.next;
                    if (count % 2 == 1){ // 奇数
                            p.next = null;
                            oddTail.next = p;
                            oddTail = p;
                    } else { // 偶数
                            p.next = null;
                            evenTail.next = p;
                            evenTail = p;
                    }
                    count++;
                    p = tmp;
             }
            oddTail.next = evenHead.next;
            return oddHead.next;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 創建奇數結果鏈表、創建偶數結果鏈表
    • 遍歷原始鏈表，用count計數確認指針指向的是奇數或偶數，如果是奇數則尾差至奇數結果鏈表，如果是偶數則尾差至偶數結果鏈表，遍歷結束後將偶數結果鏈表合併至奇數結果鏈表，返回奇數結果連表。
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(1)
