✍🏽 My Solution

Runtime: 0 ms, faster than 100.00% of Java online submissions for Binary Tree Postorder Traversal. Memory Usage: 40.3 MB, less than 93.93% of Java online submissions for Binary Tree Postorder Traversal.

class Solution {
    List<Integer> result = new ArrayList<>();
    public List<Integer> postorderTraversal(TreeNode root) {
        postorder_r(root);
        return result;
    }
    private void postorder_r(TreeNode root) {
        if (root == null) return;
        postorder_r(root.left);
        postorder_r(root.right);
        result.add(root.val);
    }
}

Solution #1 [Iterative]

Runtime: 1 ms, faster than 50.88% of Java online submissions for Binary Tree Postorder Traversal. Memory Usage: 41.9 MB, less than 70.62% of Java online submissions for Binary Tree Postorder Traversal.

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        LinkedList<Integer> ans = new LinkedList<>();
        Stack<TreeNode> stack = new Stack<>();
        if (root == null) return ans;

        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode cur = stack.pop();
            ans.addFirst(cur.val);
            if (cur.left != null) {
                stack.push(cur.left);
            }
            if (cur.right != null) {
                stack.push(cur.right);
            } 
        }
        return ans;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 我们可以用 LinkedList ， 这样倒置链表就只需要遍历一遍，也不需要额外的空间了。
    • 更近一步，我们在调用 list.add 的时候，其实可以直接 list.addFirst ，每次都插入到链表头，这样做的话，最后也不需要逆转链表了。（不需要下方solution#2寫法）
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(n)

Solution #2 [Iterative-前序遍歷反轉]

class Solution {
    public List<Integer> postorderTraversal(TreeNode root) {
        List<Integer> res = new LinkedList<Integer>();
        if (root == null) {
            return res;
        }
        Stack<TreeNode> stack = new Stack<>();
        TreeNode cur = root;
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);
            if (node.left != null) {
                stack.push(node.left);
            }
            if (node.right != null) {
                stack.push(node.right);
            }
        }
        Collections.reverse(res);
        return res;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 這個方法有點取巧，不是正統模擬壓棧的做法
    • 前序輸出的順序是：中左右，那我們調換押入stack，先壓左再壓右，輸出就會變成：中右左
    • 再反轉list，就會變成後續遍歷的輸出順序：左右中
