class MyHashMap {
    private int size;
    private Node[] buckets;
    private static final double LOAD_FACTOR = 0.75;

    public MyHashMap() {
        size = 0;
        buckets = new Node[16];
    }

    private class Node {
        public int key;
        public int value;
        public Node next;
        public Node (int key, int value){
            this.key = key;
            this.value = value;
            this.next = null;
        }
    }

    public void put(int key, int value) {
        int index = hash(key);
        Node head = buckets[index];

        while (head != null && head.key != key) {
            head = head.next;
        }

        if (head != null) {
            head.value = value;
        } else {
            Node newNode = new Node(key, value);
            newNode.next = buckets[index];
            buckets[index] = newNode;
            size++;
        }

        if (size >= (buckets.length * LOAD_FACTOR)) {
            expand();
        }

    }

    public int get(int key) {
        int index = hash(key);
        Node head = buckets[index];

        while (head != null) {
            if (head.key == key) {
                return head.value;
            }
            head = head.next;
        }
        return -1;
    }

    public void remove(int key) {
        int index = hash(key);
        Node head = buckets[index];

        if (head == null) return;

        Node dummy = new Node(0,0);
        Node cur = dummy;
        dummy.next = head;

        while (cur.next != null) {
            if (cur.next.key == key) {
                cur.next = cur.next.next;
                size--;
                break;
            }
            cur = cur.next;
        }
        buckets[index] = dummy.next;
    }

    // 創建新的哈希表容器(size*2)
    // 把原先哈希表內的(key, value)重新put()
    private void expand() {
        Node[] oldBuckets = buckets;
        Node[] newBuckets = new Node[buckets.length * 2];
        buckets = newBuckets;

        for (Node head : oldBuckets) {
            while (head != null) {
                put(head.key, head.value);
                head = head.next;
            }
        }
    }

    private int hash(int key) {
        return key % buckets.length;
    }
}

🧠 Thought Process

  • What mistakes did I make?
    • remove() 忘記最後 buckets[index] = dummy.next; 因為刪除的有可能是頭節點 要記得再加回去
    • Put() 這個會寫錯
      • newNode.next = buckets[index]; buckets[index] = newNode;
      • 都會寫成head 這樣是錯的

Solution #1 [圖靈星球]

Runtime: 16 ms, faster than 92.73% of Java online submissions for Design HashMap. Memory Usage: 49.8 MB, less than 86.25% of Java online submissions for Design HashMap.

class MyHashMap {
    private Node[] buckets;
    private int size;
    private static final double LOAD_FACTOR = 0.75;

    public MyHashMap() {
        size = 0;
        buckets = new Node[16];
    }

    private class Node {
        public int key;
        public int value;
        public Node next;

        public Node(int key, int value) {
            this.key = key;
            this.value = value;
            next = null;
        }
    }

    // 計算 hashCode(key)=x
    // 找到對應的 index = X % size
    // 在hashMap[index]的chain裡查看是否已經存在key
        // 1.存在 -> 更新對應的value
        // 2.不存在 -> 在chain裡加入創建新的(key,value) 頭尾都可以
        // 3.size++
    // 檢查load factor，看是否達到擴容條件
    public void put(int key, int value) {
        int index = hash(key);
        Node head = buckets[index];

        while (head != null && head.key != key) {
            head = head.next;
        }

        // 存在 -> 更新對應的value
        if (head != null) {
            head.value = value;
        } else { // 不存在 -> 在chain頭部加入創建新的(key,value) 頭尾都可以
            Node newNode = new Node(key, value);
            newNode.next = buckets[index];
            buckets[index] = newNode;
            size++;
        }

        if (size >= buckets.length * LOAD_FACTOR) {
            expand();
        }

    }

    // 計算 hashCode(key)=x
    // 找到對應的 index = X % size
    // 在hashMap[index]的chain裡查看是否已經存在key
        // 1.存在 -> 返回對應的value
        // 2.不存在 -> 返回-1
    public int get(int key) {
        int index = hash(key);
        Node head = buckets[index];

        while (head != null && head.key != key) {
            head = head.next;
        }

        return head == null ? -1 : head.value;
    }

    // 計算 hashCode(key)=x
    // 找到對應的 index = X % size
    // 在hashMap[index]的chain裡查看是否已經存在key
        // 1.存在 -> 刪除對應的value
        // 2.不存在 -> 什麼都不做
    //size--
    public void remove(int key) {
        int index = hash(key);
        Node head = buckets[index];

        Node dummy = new Node(0, 0);
        Node cur = dummy;
        dummy.next = head;

        while (cur.next != null && cur.next.key != key) {
            cur = cur.next;
        }

        // 存在 -> 刪除對應的value
        if (cur.next != null && cur.next.key == key) {
            cur.next = cur.next.next;
            size--;
        }
        // 有可能chain的Head是我們要移除的Node，故head變了
                // buckets[index]原本的值是舊的head，所以要更新成新的值
        buckets[index] = dummy.next;

    }

    // 哈希函數
    private int hash(int key) {
        return key % buckets.length;
    }

    // 創建新的哈希表容器(size*2)
    // 把原先哈希表內的(key, value)重新put()
    private void expand() {
        Node[] oldBuckets = buckets;
        Node[] newBuckets = new Node[buckets.length *2];
        buckets = newBuckets;

        for (Node head : oldBuckets) {
            while (head != null) {
                put(head.key, head.value);
                head = head.next;
            }
        }
    } 

}

Explanation (in my words)

  • How does their solution work?
    • 哈希衝突的時候，這道題使用拉鍊法(Chaining)解決衝突
      • 把哈希表的每個位置做成一個LinkedList
      • 對於同一個位置的key把他們串在一起
    • get 先找到哈希表對應的chain，從chain裡面找到真正的key
    • 擴容：
      • 什麼時候擴容哈希表
        • 完全滿了
          • 比如有100個位置，現在99個位置都被填充了，那麼新的key很難保證哈希值會落在空的位置，導致出現很多重複，哈希表很難被填滿
        • 快要滿了 我們應該在快滿的時候擴容，那到底要多滿呢？
          • 不能太滿才擴容：會出現很多重複，導致搜索時間上升
          • 不能太空就擴容：空間浪費太多
          • Java引入了Load Factor的概念，當哈希表裡的元素個數超過 size * load factor的時候就會擴容 （size * 2）
          • load factor = 0.75 in java

Solution #2 [王爭-使用Java的LinkedList接口]

Runtime: 18 ms, faster than 89.61% of Java online submissions for Design HashMap. Memory Usage: 61.5 MB, less than 65.26% of Java online submissions for Design HashMap.

class MyHashMap {
    private class Pair {
        public int key;
        public int value;

        public Pair(int key, int value) {
            this.key = key;
            this.value = value;
        }
    }
    private static final int SLOTS_COUNT = 3535; // 不是很重要，多少都可以
    private LinkedList<Pair>[] slots;

    public MyHashMap() {
        slots = new LinkedList[SLOTS_COUNT];
    }

    // 哈希函數
    private int hash(int key) {
        return key % SLOTS_COUNT;
    }

    public void put(int key, int value) {
        // 計算哈希值後取出鏈表（這裡的鏈表是Java提供的接口）
        LinkedList<Pair> slot = slots[hash(key)]; 

        // 如果鏈表為空，新增一個鏈表，將計算後的哈希值存入
        if (slot == null) { 
            slots[hash(key)] = new LinkedList<>();
            slot = slots[hash(key)];
        }

        // 遍歷查找鏈表看是否有重複的，如果有就刪除
        // Java 有提供for遍歷的方式遍歷鏈表，底層也是鏈表的遍歷方式
        for (int i = 0; i < slot.size(); i++) {
            Pair pair = slot.get(i);
            if (pair.key == key) {
                slot.remove(i);
                break;
            }
        }
        // 插入鏈表
        slot.add(new Pair(key, value));
    }

    public int get(int key) {
        // 計算哈希值後取出鏈表（這裡的鏈表是Java提供的接口）
        LinkedList<Pair> slot = slots[hash(key)];
        // 鏈表為空直接返回
        if (slot == null) {
            return -1;
        }
        // 鏈表不為空，遍歷鏈表，找到key返回值
        for (int i = 0; i < slot.size(); i++) {
            Pair pair = slot.get(i);
            if (pair.key == key) {
                return pair.value;
            }
        }
        return -1;
    }

    public void remove(int key) {
        LinkedList<Pair> slot = slots[hash(key)];
        if (slot == null) {
            return;
        }
        for (int i = 0; i < slot.size(); i++) {
            Pair pair = slot.get(i);
            if (pair.key == key) {
                slot.remove(i); // Java LinkedList提供的remove接口
                break;
            }
        }
    }
}
