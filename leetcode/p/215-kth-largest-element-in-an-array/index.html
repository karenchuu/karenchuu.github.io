class Solution {
    public int findKthLargest(int[] nums, int k) {
        if (nums.length < k) return -1;
        shuffle(nums);
        return quickSort(nums, 0, nums.length - 1, k - 1);
    }

        private int quickSort(int[] nums, int left, int right, int k) {
        if (left > right) return -1;
        int pi = partition(nums, left, right);
        if (pi == k) {
            return nums[pi];
        } else if (pi < k) { //从右边去继续寻找
            return quickSort(nums, pi+1, right, k);
        } else { //从左边去继续寻找
            return quickSort(nums, left, pi-1, k);
        }
    }

    private int partition(int[] nums, int left, int right) {
        int i = left;
        for (int j = left; j < right; j++) {
            if (nums[j] > nums[right]) {
                swap(nums, i, j);
                i++;
            }
        }
        swap(nums, i, right);
        return i;
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }
    private void shuffle(int[] nums) {
        final Random random = new Random();
        for(int ind = 1; ind < nums.length; ind++) {
            final int r = random.nextInt(ind + 1); // [ind~r)
            swap(nums, ind, r);
        }
    }
}

  • Why did I choose this particular implementation?

    • 使用快速排序的思想。 選定結尾元素當作分區點，左邊都是大於分區點的數，右邊都是小於分區點的數

    • 左部分的个数记做 m。

      如果 k == m + 1，我们把分区点返回即可。

      如果 k > m + 1，说明第 k 大数在右边，我们在右边去寻找第 k - m - 1 大的数即可。

      如果 k < m + 1，说明第 k 大数在左边，我们在左边去寻找第 k 大的数即可。

    • 左边和右边寻找在代码中采取递归即可。

    Solution #3 [quick select]

class Solution {
    public int findKthLargest(int[] nums, int k) {
        int n = nums.length;
        shuffle(nums);
        return quickSort(nums, 0, n-1, k);
    }

    private int quickSort(int[] nums, int left, int right, int k) {
        if (left > right) return -1;
        int pivot = partition(nums, left, right); // 獲取分區點下標
        int count = pivot - left + 1; // 紀錄分區點是第幾個元素
        if (count == k) {
            return nums[pivot];
        } else if (count < k) { //从右边去继续寻找
            return quickSort(nums, pivot+1, right, k - count);
        } else { //从左边去继续寻找
            return quickSort(nums, left, pivot-1, k);
        }
    }

    // 獲取分區點
    private int partition(int[] nums, int left, int right) {
        int pivot = nums[right];
        int i = left;
        for (int j = left; j < right; j++) {
            if (nums[j] > pivot) {
                swap(nums, i, j);
                i++;
            }
        }
        swap(nums, i, right);
        return i;
    }

    private void swap(int[] nums, int i, int j) {

        shuffle(nums);
        return quickSort(nums, 0, n-1, k);

    private int quickSort(int[] nums, int left, int right, int k) {
        if (left > right) return -1;
        int pivot = partition(nums, left, right); // 獲取分區點下標
        int kPos = nums.length - k; // 紀錄分區點是第幾個元素
        if (pivot == kPos) {
            return nums[pivot];

            return quickSort(nums, pivot+1, right, k);

        }

Explanation (in my words)

  • How does their solution work?

    • 对于顺序数组或者逆序数组来说，拆分的子問題的規模只比原本減少了一個元素，每一次劃分只能確定一個位置，就會導致递归树高度增加（非常不平衡、递归树倾斜），就會變成選擇排序，時間複雜度就降低O(n^2)

      解法：破壞順序性

      1. 把數組順序打亂
      2. 隨機選擇 pivot

      shuffle是避免worst case，如果已經是排好序的

      快速排序理想就是遞歸樹平衡，排序越隨機越好

Solution #2 [quick sort]

Runtime: 4 ms, faster than 81.38% of Java online submissions for Kth Largest Element in an Array. Memory Usage: 42.4 MB, less than 89.92% of Java online submissions for Kth Largest Element in an Array.

class Solution {
    public int findKthLargest(int[] nums, int k) {
        int n = nums.length;
        shuffle(nums);
        quickSort(nums, 0, n-1);
        return nums[n-k];
    }
    private void quickSort(int[] nums, int left, int right) {
        if (left >= right) return;
        int pivot = partition(nums, left, right); // 獲取分區點下標
        quickSort(nums, left, pivot - 1);
        quickSort(nums, pivot + 1, right);
    }

    // 獲取分區點
    private int partition(int[] nums, int left, int right) {
        int pivot = nums[right];
        int i = left;
        for (int j = left; j < right; j++) {
            if (nums[j] < pivot) {
                swap(nums, i, j);
                i++;
            }
        }
        swap(nums, i, right);
        return i;
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }

    private void shuffle(int[] nums) {
        final Random random = new Random();
        for(int ind = 1; ind < nums.length; ind++) {
            final int r = random.nextInt(ind + 1);
            swap(nums, ind, r);
        }
    }
}

    • 在排序前，先打亂數組
    • 利用快速排序，排序完後返回第二大的值

Solution #1 [Heap]

class Solution {
    public int findKthLargest(int[] nums, int k) {
        int n = nums.length;
        PriorityQueue<Integer> minHeap = new PriorityQueue<>((o1, o2) -> o1 - o2);
        for (int i = 0; i < n; i++) {
            minHeap.offer(nums[i]);
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }
        return minHeap.peek();
    }
}

Explanation (in my words)

  • How does their solution work?
    • 維護一個小頂堆，小頂堆的功用就是，當插入元素的時候，較大的元素會一直往下沈殿，較小的元素會浮上來
    • 當Heap裡面的元素超過k，就把頂部的元素刪除，因為頂部的元素是比較小的
    • 當遍歷完數組之後，堆頂元素就是我們想要的第k大的元素
  • What is the space/time complexity of their solution?
    • timeL O(nlogk)

二叉堆插入和删除的时间复杂度和堆中的元素个数有关，在这里我们堆的大小不会超过 k ，所以插入和删除元素的复杂度是 O(logK)，再套一层 for 循环，总的时间复杂度就是 O(NlogK)。
