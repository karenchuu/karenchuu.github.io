class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> path = new ArrayList<>();
        buildParenthesis(new StringBuilder(), 0, 0, path, n);
        return path;
    }

    private void buildParenthesis(StringBuilder sb, int usedLeft, int usedRight, List<String> path, int n) {
        if (usedRight == n) {
            path.add(sb.toString());
        }

        if (usedLeft < n) {
            sb.append("(");
            buildParenthesis(sb, usedLeft + 1, usedRight, path, n);
            sb.setLength(sb.length() - 1);
        }

        if (usedRight < usedLeft) {
            sb.append(")");
            buildParenthesis(sb, usedLeft, usedRight + 1, path, n);
            sb.setLength(sb.length() - 1);
        }
    }
}

class Solution {
    private List<String> result = new ArrayList<>();

    public List<String> generateParenthesis(int n) {
        char[] path = new char[2*n];
        backtrack(n, 0, 0, 0, path);
        return result;
    }

    private void backtrack(int n, int usedLeft, int usedRight, int k, char[] path) {
        if (k == 2*n) {
            result.add(String.valueOf(path));
            return;
        }

        if (usedLeft < n) {
            path[k] = '(';
            backtrack(n, usedLeft+1, usedRight, k+1, path);
        }

        if (usedLeft > usedRight) {
            path[k] = ')';
            backtrack(n, usedLeft, usedRight+1, k+1, path);
        }
    }
}

Explanation (in my words)

  • How does their solution work?
    • 用過的左括號 < n，可以使用左誇號
    • 用過的左括號 > 用過的右括號，可以使用右括號

Solution #2 [Backtrack]

Runtime: 1 ms, faster than 97.45% of Java online submissions for Generate Parentheses.

Memory Usage: 42.5 MB, less than 86.53% of Java online submissions for Generate Parentheses.

class Solution {
    public List<String> generateParenthesis(int n) {
        List<String> res = new LinkedList<>();
        backtrack("", 0, 0, res, n);
        return res;
    }

    private void backtrack(String curr, int left, int right, List<String> res, int n){
        if (right == n) {
            res.add(curr);
            return;
        }
        if (left < n) {
            backtrack(curr + "(", left + 1, right, res, n);
        }
        if (right < left) {
            backtrack(curr + ")", left, right + 1, res, n);
        }
    }
}

Explanation (in my words)

  • How does their solution work?
    • [Leetcode 22]Generate Parentheses
    • 就是不停选括号，要么选左括号，要么选右括号。
    • left 记录已经放入的左括号的数量; right 记录右括号的数量；curr 表示当前组成的字符串
