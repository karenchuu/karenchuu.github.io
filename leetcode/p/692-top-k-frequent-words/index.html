class Solution {
    List<String> res = new ArrayList<>();
    HashMap<String, Integer> freq;
    String[] unique;
    public List<String> topKFrequent(String[] words, int k) {
        int n = words.length;
        freq = new HashMap<>();
        for (int i = 0; i < n; i++) {
            freq.put(words[i], freq.getOrDefault(words[i], 0) + 1);
        }
        int N = freq.size();
        unique = new String[N];
        int i = 0;
        for (String s : freq.keySet()) {
            unique[i] = s;
            i++;
        }
        return quick(0, N-1, k-1);
    }

    private List<String> quick(int left, int right, int k) {
        if (left > right) return new ArrayList<>();
        int pivot = partition(left, right);
        if (pivot == k) {
            Arrays.sort(unique, 0, k, (a, b) -> { 
                int x = freq.get(b) - freq.get(a);
                if (x == 0)
                    return a.compareTo(b);
                return x;
            });
            for(int i = 0; i <= k; i++)
                res.add(unique[i]);

            return res;
        } else if (pivot > k) {
            return quick(left, pivot-1, k);
        } else {
            return quick(pivot+1, right, k);
        }
    }

    private int partition(int left, int right) {
        int pivot_freq = freq.get(unique[right]);
        int i = left;
        for (int j = left; j < right; j++) {
            if (freq.get(unique[j]) > pivot_freq) {
                swap(unique, i, j);
                i++;
                        // 如果此字符串小于字符串参数，则返回一个小于 0 的值；
            } else if (freq.get(unique[j]) == pivot_freq && unique[j].compareTo(unique[right]) < 0){
                swap(unique, i, j);
                i++;
            }
        }
        swap(unique, right, i);
        return i;
    }

    private void swap(String[] arr, int i, int j) {
        String tmp = arr[i];
        arr[i] = arr[j];
        arr[j] = tmp;
    }
}

Solution #1 [MinHeap]

Runtime: 12 ms, faster than 32.76% of Java online submissions for Top K Frequent Words. Memory Usage: 45.9 MB, less than 9.60% of Java online submissions for Top K Frequent Words.

class Solution {
    public List<String> topKFrequent(String[] words, int k) {
        int n = words.length;
        List<String> res = new ArrayList<>();
        HashMap<String, Integer> wordToFreq = new HashMap<>();
        for (int i = 0; i < n; i++) {
            wordToFreq.put(words[i], wordToFreq.getOrDefault(words[i], 0) + 1);
        }
        // 1）词频大的靠前 2）词频相同，字典序小的靠前
        PriorityQueue<String> pq = new PriorityQueue<>(
            (a, b) -> wordToFreq.get(a).equals(wordToFreq.get(b)) ? b.compareTo(a) : wordToFreq.get(a) - wordToFreq.get(b));

        for (String word : wordToFreq.keySet()) {
            pq.offer(word);
            if (pq.size() > k) {
                pq.poll();
            }
        }

        while (!pq.isEmpty()) {
            res.add(pq.poll());
        }
        Collections.reverse(res);
        return res;
    }
}

Explanation (in my words)

  • How does their solution work?

    • 建立HashMap記錄每個單詞出現的頻率
    • 用小頂堆紀錄頻率，判斷如果相同頻率，要用字典的方式由小到大排序
    • 依序將單詞加入小頂堆，如果小頂堆大於k個元素，就把棧頂元素彈出，這樣就可以一直維持前k大元素

    • CompareTo 輸入String，可以按字典顺序比较两个字符串。

      • 如果词频不相等，根据词频进行升序构建，确保堆顶元素是堆中词频最小的元素 如果词频相等，根据字典序大小进行倒序构建。

        以上兩個條件可以确保堆顶元素是堆中「词频最小 & 字典序最大」的元素（就代表這個元素會是小頂堆會最先彈出的元素）

    • 輸出的時候需要頻率由高到低排序，故輸出的順序原本是由小到大，需要反轉，反轉有3個方法

      • res.add(0, pq.poll());
      • Collections.reverse(res);
      • use a linkedlist and use addFirst
    • What is the space/time complexity of their solution?
    • time: O(nlogk)
    • space: O(k)

Solution #2 [Bucket Sort]

Runtime: 10 ms, faster than 56.22% of Java online submissions for Top K Frequent Words. Memory Usage: 45.7 MB, less than 18.87% of Java online submissions for Top K Frequent Words.

class Solution {
    public List<String> topKFrequent(String[] words, int k) {
        List<String>[] buc = new List[words.length +1];
        HashMap<String, Integer> map = new HashMap<>();
        List<String> ans = new ArrayList<>();

        for(String str : words) 
            map.put(str, map.getOrDefault(str, 0) +1);

        for(String key : map.keySet()) {
            int freq = map.get(key);

            if(buc[freq] == null) {
                buc[freq] = new ArrayList<String>();
            }
            buc[freq].add(key);
        }

        for(int i = buc.length -1; i >= 0 && ans.size() < k; i--) {
            if(buc[i] != null) {
                Collections.sort(buc[i]);
                ans.addAll(buc[i]);
            }
        }

        return ans.subList(0,k); // 取list的 [0,k)
    }
}

Explanation (in my words)

  • How does their solution work?
    • 因為最後要對字典排序，所以要 Collections.sort(buc[i]); 方法存在於java.util.Collections類中。它用於按升序對出現在Collection的指定列表中的元素進行排序。
