✍🏽 My Solution - minHeap

Runtime: 10 ms, faster than 89.32% of Java online submissions for Top K Frequent Elements. Memory Usage: 44.7 MB, less than 94.46% of Java online submissions for Top K Frequent Elements.

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        HashMap<Integer, Integer> map = new HashMap<>();
        int n = nums.length;
        for (int i = 0 ; i < n; i++) {
            map.put(nums[i], map.getOrDefault(nums[i], 0) + 1);
        }
        PriorityQueue<Integer> pq = new PriorityQueue<>((o1, o2) -> (map.get(o1) - map.get(o2)));
        for (Integer key : map.keySet()) {
            pq.offer(key);
            if (pq.size() > k) {
                pq.poll();
            }
        }
        int[] res = new int[k];
        for (int i = 0; i < k; i++) {
            res[i] = pq.poll();
        }
        return res;
    }
}

  • Why did I choose this particular implementation?
    • 有參考力扣解答，跟王爭的解法差不多，但是寫法比較簡潔，不用額外創建對象
    • 建立哈希表統計每個數字出現的次數
    • 建立優先級隊列（小頂堆），方便刪除操作
    • 遍歷map的key
      • 如果 minQueue 大小還沒超過k，直接將 map 的 key 加入小頂堆
      • 如果 map 的 key 次數大於堆頂，移除堆頂（最小值），插入map 的 key
  • What is the time/space complexity of my solution? How do I know?
    • 时间复杂度：O(nlogk)，n 表示数组的长度。首先，遍历一遍数组统计元素的频率，这一系列操作的时间复杂度是 O(n)；接着，遍历用于存储元素频率的 map，如果元素的频率大于最小堆中顶部的元素，则将顶部的元素删除并将该元素加入堆中，这里维护堆的数目是 k，所以这一系列操作的时间复杂度是 O(nlogk)的；因此，总的时间复杂度是 O(nlog⁡k)。
    • 空间复杂度：O(k)，最坏情况下（每个元素都不同），map 需要存储 n 个键值对，优先队列需要存储 k 个元素，因此，空间复杂度是 O(n)。

Solution #1 [max Heap]

Runtime: 19 ms, faster than 47.78% of Java online submissions for Top K Frequent Elements.

Memory Usage: 49.8 MB, less than 74.97% of Java online submissions for Top K Frequent Elements.

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        HashMap<Integer, Integer> map = new HashMap<>();
        int n = nums.length;
        for (int i = 0; i < n; i++) {
            map.put(nums[i], map.getOrDefault(nums[i], 0) + 1);
        }
        PriorityQueue<Integer> minQueue = new PriorityQueue<>((o1, o2) -> map.get(o2) - map.get(o1));
        minQueue.addAll(map.keySet());

        int[] result = new int[k];
        for (int i = 0; i < k; i++) {
            result[i] = minQueue.poll();
        }
        return result;
    }
}

Solution #2 [quick select]

Runtime: 9 ms, faster than 97.78% of Java online submissions for Top K Frequent Elements. Memory Usage: 44.8 MB, less than 92.62% of Java online submissions for Top K Frequent Elements.

// 1. 快速選擇 O(nlogn)
// 2. 小頂堆 O(nlogk)
// 3. bucketSort
// 4. countSort
class Solution {
    int[] unique;
    HashMap<Integer, Integer> frequentMap;
    public int[] topKFrequent(int[] nums, int k) {
        frequentMap = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            frequentMap.put(nums[i], frequentMap.getOrDefault(nums[i], 0) + 1);
        }
        // 1:3 2:2 3:1
        // unique: 1 2 3
        // 1 2 3
        unique = new int[frequentMap.size()];
        int n = unique.length;
        shuffle(unique);
        int i = 0;
        for (Integer key : frequentMap.keySet()) {
            unique[i] = key;
            i++;
        }
        return quickSort(0, n-1, k-1);
    }

    private int[] quickSort(int left, int right, int k) {
        if (left > right) return new int[0];
        int pivot = partition(left, right);
        if (pivot == k) {
            return Arrays.copyOf(unique, pivot+1);
        } else if (pivot > k) {
            return quickSort(left, pivot-1, k);
        } else {
            return quickSort(pivot+1, right, k);
        }
    }

    private int partition(int left, int right) {
        int pivot_freq = frequentMap.get(unique[right]);
        int i = left;
        for (int j = left; j < right; j++) {
            if (frequentMap.get(unique[j]) > pivot_freq) {
                swap(unique, i, j);
                i++;
            }
        }
        swap(unique, i, right);
        return i;
    }

    private void swap(int[] nums, int i, int j) {
        int tmp = nums[i];
        nums[i] = nums[j];
        nums[j] = tmp;
    }

    private void shuffle(int[] nums) {
        Random r = new Random();
        int range = nums.length;
        for (int i = 0; i < range; i++) {
            int swapIdx = r.nextInt(range);
            swap(nums, i, swapIdx);
        }
    }
}

Explanation (in my words)

  • How does their solution work?
    • 使用快速排序由大到小，之後取第k個
  • What is the space/time complexity of their solution?
    • time: avg O(n), worst case O(n^2) 避免最壞情況可以採用 1. random pivot 2. shuffle array
    • space: O(n)

Solution #3 [Bucket Sort]

Runtime: 14 ms, faster than 77.83% of Java online submissions for Top K Frequent Elements. Memory Usage: 51.3 MB, less than 16.75% of Java online submissions for Top K Frequent Elements.

class Solution {
    public int[] topKFrequent(int[] nums, int k) {
        List<Integer> res = new ArrayList<>();
        // 使用字典，统计每个元素出现的次数，元素为键，元素出现的次数为值
        HashMap<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            map.put(nums[i], map.getOrDefault(nums[i], 0) + 1);
        }
        //将频率作为数组下标，对于出现频率不同的数字集合，存入对应的数组下标
        List<Integer>[] bucket = new List[nums.length+1]; // 別忘記！
        for (Integer key : map.keySet()) {
            // 获取出现的次数作为下标
            int frequency = map.get(key);
            if (bucket[frequency] == null) {
                bucket[frequency] = new ArrayList<>();
            }
            bucket[frequency].add(key);
        }

        // 倒序遍历数组获取出现顺序从大到小的排列
        for (int i = bucket.length - 1; i >= 0 && res.size() < k; i--) {
            if (bucket[i] != null) {
                res.addAll(bucket[i]);
            }
        }
        int[] resArr = new int[res.size()];
        for (int i = 0; i < res.size(); i++) {
            resArr[i] = res.get(i);
        }
        return resArr;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 桶排序，空間換時間
    • 先建立哈希表，存儲數字為key，該數字出現的頻率為value
    • 建立一個array，以出現的頻率為下標，將數字存在裡面
    • 倒序遍歷該數組，就可以將出現的頻率由大到小排序，加入到結果數組裡面輸出
  • What is the space/time complexity of their solution?
    • time: O(n) 嚴格的O(n)
    • space: O(n)
