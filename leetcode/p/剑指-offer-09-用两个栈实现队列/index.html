剑指 Offer 09. 用两个栈实现队列

在 LeetCode 開啟 ↗Open on LeetCode ↗
Question

用两个栈实现一个队列。队列的声明如下，请实现它的两个函数 appendTail 和 deleteHead ，分别完成在队列尾部插入整数和在队列头部删除整数的功能。(若队列中没有元素，deleteHead 操作返回 -1 )

示例 1：

输入：
["CQueue","appendTail","deleteHead","deleteHead"]
[[],[3],[],[]]
输出：[null,null,3,-1]

示例 2：

输入：
["CQueue","deleteHead","appendTail","appendTail","deleteHead","deleteHead"]
[[],[],[5],[2],[],[]]
输出：[null,-1,null,null,5,2]

提示：

  • 1 <= values <= 10000
  • 最多会对 appendTail、deleteHead 进行 10000 次调用

先自己想想看 🤔Try it yourself first 🤔

✍🏽 My Solution

class CQueue {
    private Stack<Integer> stack = new Stack<>(); 
    private Stack<Integer> tmpStack = new Stack<>(); 

    public CQueue() {

    }

    public void appendTail(int value) {
        stack.push(value);
    }

    public int deleteHead() {
        if (stack.isEmpty()) return -1;
        while (!stack.isEmpty()) {
            tmpStack.push(stack.pop());
        }
        int result = tmpStack.pop();
        while (!tmpStack.isEmpty()) {
            stack.push(tmpStack.pop());
        }
        return result;
    }
}

/**
 * Your CQueue object will be instantiated and called as such:
 * CQueue obj = new CQueue();
 * obj.appendTail(value);
 * int param_2 = obj.deleteHead();
 */

    • 栈无法实现队列功能： 栈底元素（对应队首元素）无法直接删除，需要将上方所有元素出栈。 双栈可实现列表倒序： 设有含三个元素的栈 A = [1,2,3] 和空栈 B = []。若循环执行 A 元素出栈并添加入栈 B ，直到栈 A 为空，则 A = [] , B=[3,2,1] ，即 栈 B 元素实现栈 A 元素倒序 。 利用栈 B 删除队首元素： 倒序后，B 执行出栈则相当于删除了 A 的栈底元素，即对应队首元素。

Solution #1 [王爭-兩個棧倒騰優化]

class CQueue {

    Stack<Integer> stack = new Stack<>();
    Stack<Integer> tmpStack = new Stack<>();

    public CQueue() {

    }

    public void appendTail(int value) {
        stack.push(value);
    }

    public int deleteHead() {
        if (stack.isEmpty() && tmpStack.isEmpty()) return -1; //注意tmpStack也要判斷

        int pop = 0;
        if (!tmpStack.isEmpty()) {
            pop = tmpStack.pop();
        } else {
            while (!stack.empty()) {
                tmpStack.push(stack.pop());
            }
            pop = tmpStack.pop();
        }
        return pop;
    }
}

/**
 * Your CQueue object will be instantiated and called as such:
 * CQueue obj = new CQueue();
 * obj.appendTail(value);
 * int param_2 = obj.deleteHead();
 */

Explanation (in my words)

  • How does their solution work?
    • 建立 s 跟 tmp棧
    • 入隊直接入s棧
    • 出隊，先確認 tmp 是否為空
      • 是：倒騰
      • 否：代表已經倒騰完了，就直接從tmp出隊
  • What is the space/time complexity of their solution?
    • 入隊：
      • time: O(1)
      • space: O(n)
    • 出隊
      • time: 搗騰：O(n) 、直接出隊：O(1)
      • 出隊均攤時間複雜度：O(1)
      • 对于出隊操作，虽然看起来是 O(n) 的时间复杂度，但是仔细考虑下每个元素只会「至多被插入和弹出 tmp 一次」，因此均摊下来每个元素被删除的时间复杂度仍为 O(1)。
      • space: O(n)
