✍🏽 My Solution - Recursive

Runtime: 0 ms, faster than 100.00% of Java online submissions for Binary Tree Preorder Traversal. Memory Usage: 40.3 MB, less than 90.55% of Java online submissions for Binary Tree Preorder Traversal.

class Solution {
    private List<Integer> result = new ArrayList<>();
    public List<Integer> preorderTraversal(TreeNode root) {
        preorder_r(root);
        return result;
    }

    private void preorder_r(TreeNode root) {
        if (root == null) return;
        result.add(root.val);
        preorder_r(root.left);
        preorder_r(root.right);
    }
}

Solution #1 [Stack - 模擬遞歸]

Runtime: 1 ms, faster than 49.81% of Java online submissions for Binary Tree Preorder Traversal.

Memory Usage: 42.7 MB, less than 9.65% of Java online submissions for Binary Tree Preorder Traversal.

class Solution {
    public List<Integer> preorderTraversal(TreeNode root) {
        List<Integer> res = new LinkedList<Integer>();
        Stack<TreeNode> stack = new Stack<TreeNode>();
        TreeNode cur = root;
        while (cur != null || !stack.isEmpty()) {
            if (cur != null) {
                res.add(cur.val);
                stack.push(cur);
                cur = cur.left;
            } else {
                cur = stack.pop();
                cur = cur.right;
            }
        }
        return res;
    }
}

Solution #2 [Stack - 左右子樹分別壓棧]

Runtime: 1 ms, faster than 49.81% of Java online submissions for Binary Tree Preorder Traversal. Memory Usage: 42.1 MB, less than 58.23% of Java online submissions for Binary Tree Preorder Traversal.

class Solution {
    List<Integer> res = new LinkedList<Integer>();
    public List<Integer> preorderTraversal(TreeNode root) {
        if (root == null) {
            return res;
        }
        Stack<TreeNode> stack = new Stack<>();
        stack.push(root);
        while (!stack.isEmpty()) {
            TreeNode node = stack.pop();
            res.add(node.val);
            if (node.right != null) {
                stack.push(node.right);
            }
            if (node.left != null) {
                stack.push(node.left);
            }
        }
        return res;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 我们还可以将左右子树分别压栈，然后每次从栈里取元素。 需要注意的是，因为我们应该先访问左子树，而栈的话是先进后出，所以我们压栈先压右子树。
