Question

Given an arithmetic equation consisting of positive integers, +, -, * and / (no paren­theses), compute the result.

The expression string contains only non-negative integers, +, -, *, / operators and empty spaces . The integer division should truncate toward zero.

Example 1:

Input: "3+2*2"
Output: 7

Example 2:

Input: " 3/2 "
Output: 1

Example 3:

Input: " 3+5 / 2 "
Output: 5

Note:

You may assume that the given expression is always valid. Do not use the eval built-in library function.

        Stack<Integer> stack = new Stack<>();
        int preSign = '+';
        int n = s.length();
        for (int i = 0; i < n; i++) {

                continue;
            }
            if (isDigit(c)) {
                    //找到连续的数字字符串，把它转化为整数
                int num = 0;
                while (i < n && isDigit(s.charAt(i))) {
                    num = 10 * num + s.charAt(i) - '0';
                    i++;
                }
                i--; //这个是为了抵消上面for循环中的i++
                if (preSign == '*') {
                    stack.push(stack.pop() * num);
                } else if (preSign == '/') {
                    stack.push(stack.pop() / num);
                } else if (preSign == '+') {
                    stack.push(num);
                } else if (preSign == '-') {
                    stack.push(-num);
                }
            } else { //记录前一个的符号
                preSign = c;
            }
        }
          // 把栈中的所有元素都取出来，计算他们的和
        int res = 0;
        while (!stack.isEmpty()) {
            res += stack.pop();
        }
        return res;
    }
    private boolean isDigit(char c) {
        return c >= '0' && c <= '9';
    }
}

class Solution {
    public int calculate(String s) {
    //记录每个数字前面的符号，如果是乘法和除法就直接和前面的数字运算，
    //然后在存放到栈中，如果是加法和减法直接存放到栈中
    int preSign = '+';
    Stack<Integer> stack = new Stack<>();
    int length = s.length();
    for (int i = 0; i < length; i++) {
        int ch = s.charAt(i);
        if (ch == ' ')//过滤掉空格
            continue;
        //如果是数字
        if (ch >= '0' && ch <= '9') {
            //找到连续的数字字符串，把它转化为整数
            int num = 0;
            while (i < length && (ch = s.charAt(i)) >= '0' && ch <= '9') {
                num = num * 10 + ch - '0';
                i++;
            }
            //这个是为了抵消上面for循环中的i++
            i--;
            //乘法和除法，运算之后在存放到栈中。加法和减法直接存放到栈中
            if (preSign == '*') {
                stack.push(num * stack.pop());
            } else if (preSign == '/') {
                stack.push(stack.pop() / num);
            } else if (preSign == '+') {
                stack.push(num);
            } else if (preSign == '-') {
                stack.push(-num);
            }
        } else {//记录前一个的符号
            preSign = ch;
        }
    }
    //把栈中的所有元素都取出来，计算他们的和
    int res = 0;
    while (!stack.empty()) {
        res += stack.pop();
    }
    return res;
    }
}

Explanation (in my words)

  • How does their solution work?
    • 提示中说了，是一个有效的表达式，并且只有数字，空格和'+', '-', '*', '/'组成。我们知道算术运算式先算乘除后算加减。
    • 当遇到加法或减法的时候我们没法确定要不要计算，比如2+3*4。
    • 当遇到乘法或者除法的时候我们是可以直接计算的，因为他们的优先级比较高，比如42-3我们可以直接计算42的值。或者3-4*2也是可以的。
    • 所以我们可以把不能确定是否要计算的先加入到栈中，可以直接计算的先计算，然后再加入到栈中，我们随便举个例子画个图来看下

Solution #2 [王爭]

执行用时：41 ms, 在所有 Java 提交中击败了14.00%的用户

class Solution {
    public int calculate(String s) {
        Stack<Integer> nums = new Stack<>();
        Stack<Character> ops = new Stack<>();
        int i = 0;
        int n = s.length();
        while (i < n) {
            char c = s.charAt(i);
            if (c == ' ') { // 跳過空格
                i++;
            } else if (isDigit(c)) { // 數字
                int number = 0;
                while (i < n && isDigit(s.charAt(i))) {
                    number = number*10+(s.charAt(i)-'0');
                    i++;
                }
                nums.push(number);
            } else { // 運算符
                if (ops.isEmpty() || prior(c, ops.peek())) {
                    ops.push(c);
                } else {
                    while (!ops.isEmpty() && !prior(c, ops.peek())) {
                        fetchAndCal(nums, ops);
                    }
                    ops.push(c);
                }
                i++;
            }
        }
        while (!ops.isEmpty()) {
            fetchAndCal(nums, ops);
        }
        return nums.pop();
    }
    // 判斷運算符優先級
    private boolean prior(char a, char b) {
        if ((a == '*' || a == '/')
        && (b == '+' || b == '-')) {
            return true;
        }
        return false;
    }

    private int cal(char op, int number1, int number2) {
        switch(op) {
            case '+': return number1+number2;
            case '-': return number1-number2;
            case '*': return number1*number2;
            case '/': return number1/number2;
        }
        return -1;
    }

    // 是否為數字
    private boolean isDigit(char c) {
        return c >= '0' && c <= '9';
    }

    // 拿出數字棧裡面兩個數字，拿出運算符棧一個符號，然後計算
    private void fetchAndCal(Stack<Integer> nums, Stack<Character> ops) {
        int number2 = nums.pop();
        int number1 = nums.pop();
        char op = ops.pop();
        int ret = cal(op, number1, number2);
        nums.push(ret); //計算完後將結果入數字棧
    }
}

Explanation (in my words)

  • How does their solution work?
    • 數字直接入數字棧
    • 運算棧存運算符
      • 棧為空直接入棧
      • 棧不為空
        • 如果目前運算符優先級 > 棧頂運算符，將字符入棧
        • 如果目前運算符優先級 ≤ 棧頂運算符，棧頂字符出棧，然後拿運算棧的字符計算後入運算棧
    • 如果棧內還有數據，處理運算棧內剩下的計算出的结果
