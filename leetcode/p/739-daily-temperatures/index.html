739. Daily Temperatures

Question

Given an array of integers temperatures represents the daily temperatures, return an array answer such that answer[i] is the number of days you have to wait after the ith day to get a warmer temperature. If there is no future day for which this is possible, keep answer[i] == 0 instead.

Example 1:

Input: temperatures = [73,74,75,71,69,72,76,73]
Output: [1,1,4,2,1,1,0,0]

Example 2:

Input: temperatures = [30,40,50,60]
Output: [1,1,1,0]

Example 3:

Input: temperatures = [30,60,90]
Output: [1,1,0]

Constraints:

  • 1 <= temperatures.length <= 105
  • 30 <= temperatures[i] <= 100

✍🏽 My Solution

class Solution {
    public int[] dailyTemperatures(int[] temperatures) {
        int n = temperatures.length;
        int[] result = new int[n];
        Stack<Integer> stack = new Stack<>();
        for (int i = 0; i < n; i++) {
            // 一直拿現在的i元素跟棧頂元素比較
            while (!stack.isEmpty() && temperatures[i] > temperatures[stack.peek()]) {
                int idx = stack.pop();
                                result[idx] = i - idx; // 計算差距多少天
            }
            stack.push(i);
        }
        return result;
    }
}

public int[] dailyTemperatures(int[] temperatures) {
    int[] stack = new int[temperatures.length];
    int top = -1;
    int[] ret = new int[temperatures.length];
    for(int i = 0; i < temperatures.length; i++) {
        while(top > -1 && temperatures[i] > temperatures[stack[top]]) {
            int idx = stack[top--];
            ret[idx] = i - idx;
        }
        stack[++top] = i;
    }
    return ret;
}

Solution #2 [王爭-單調棧]

Runtime: 211 ms, faster than 16.36% of Java online submissions for Daily Temperatures.

// 單調棧解法
// 比較不好分析，用參照物時間複雜度分析：棧每次出棧入棧多少次（最多入棧n次、出棧n次）
// 時間複雜度：O(n)
class Solution {
        public int[] dailyTemperatures(int[] T) {
                int n = T.length;
                int result[] = new int[n];
                Stack<Integer> stack = new Stack<>();
                for (int i = 0; i < n; ++i) {
                        // 棧為空or棧頂溫度值大於T[i] 停止循環
                        while (!stack.empty() && T[stack.peek()] < T[i]) {
                                int idx = stack.pop();
                                result[idx] = i - idx; // 計算差距多少天
                        }
                        stack.push(i);
                }
                return result; // 因為int陣列初始化時已經給0，故不用特殊處理
        }
}

Explanation (in my words)

  • How does their solution work?
    • 建議一個棧，儲存元素的下標
    • 如果後面沒有比前一個溫度高，入棧
    • 如果後面比前面高，則計算後面跟棧頂元素下標的差距天數，將棧頂元素出
    • 入棧後面一個元素，循環直到遍歷結束

    • time: 比較不好分析，用參照物時間複雜度分析：看棧每次出棧入棧多少次（stack.push(i) 最多入棧n次、stack.pop()出棧n次）
    • space: O(n)
