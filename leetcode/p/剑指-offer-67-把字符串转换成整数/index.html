剑指 Offer 67. 把字符串转换成整数

在 LeetCode 開啟 ↗
Question

注意：本题与主站 8 题相同：https://leetcode-cn.com/problems/string-to-integer-atoi/

写一个函数 StrToInt，实现把字符串转换成整数这个功能。不能使用 atoi 或者其他类似的库函数。

首先，该函数会根据需要丢弃无用的开头空格字符，直到寻找到第一个非空格的字符为止。

当我们寻找到的第一个非空字符为正或者负号时，则将该符号与之后面尽可能多的连续数字组合起来，作为该整数的正负号；假如第一个非空字符是数字，则直接将其与之后连续的数字字符组合起来，形成整数。

该字符串除了有效的整数部分之后也可能会存在多余的字符，这些字符可以被忽略，它们对于函数不应该造成影响。

注意：假如该字符串中的第一个非空格字符不是一个有效整数字符、字符串为空或字符串仅包含空白字符时，则你的函数不需要进行转换。

在任何情况下，若函数不能进行有效的转换时，请返回 0。

说明：

假设我们的环境只能存储 32 位大小的有符号整数，那么其数值范围为 [−231,  231 − 1]。如果数值超过这个范围，请返回  INT_MAX (231 − 1) 或 INT_MIN (−231) 。

Solution #1 [technique]

// time: O(n)
// space: O(1)
// example:
// " -42" 前置空格，有符號 retrun -42
// "+1" return 1
// "" 空字符串 return 0
// "    " 全空格 return 0
// "abc62" return 0
// "62abc" return 62
// "9182838383838" 超過整數範圍 return Integer.MAX_VALUE
// "-9182838383838" 超過整數範圍 return Integer.MIN_VALUE

class Solution {
    public int strToInt(String str) {
        char[] chars = str.toCharArray();
        int len = chars.length;
        int sign = 1;
        if (len == 0) return 0;

        // 處理前置空格
        int i = 0;
        while (i < len && chars[i] == ' ') {
            i++;
        }
        // 全空格
        if (i == len) return 0;

        // 標記是否為正負號
        char c = chars[i];
        if (c == '-') {
            sign = -1;
            i++;
        } else if (c == '+') {
            sign = 1;
            i++;
        }
        // 處理數字，確認數字不超過32位 [-2^31, 2^31 - 1] 
        // 整數範圍-2147483648~2147483647
        int intAbsHigh = 214748364; // 略過最後一位
        int result = 0;
        while (i < len && chars[i] >= '0' && chars[i] <= '9') {
            int d = chars[i] - '0'; // 轉數字

            // 先判斷是否越界
            if (result > intAbsHigh) {
                if (sign == 1) return Integer.MAX_VALUE;
                else return Integer.MIN_VALUE;
            }
            if (result == intAbsHigh) {
                if ((sign == 1) && d > 7) return Integer.MAX_VALUE;
                if ((sign == -1) && d > 8) return Integer.MIN_VALUE;
            }

            // 沒越界就轉成數字
            result = result * 10 + d;
            i++;
        }
        return sign * result;
    }
}
