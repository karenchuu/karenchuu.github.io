class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        HashMap<String, List<String>> map = new HashMap<>();
        // 掃描每個字符串
        for(String str : strs) { 
            char[] arr = str.toCharArray(); 
            Arrays.sort(arr); // 轉成字符數組再排序
            String key = new String(arr); 
            // 如果有值，把value的List<String> 取出，沒有的話就返回空的ArrayList
            List<String> list = map.getOrDefault(key, new ArrayList<String>());
            list.add(str);
            map.put(key, list);
        }
        return new ArrayList<List<String>>(map.values());
    }
}

Solution #1 [王爭-哈希表]

Runtime: 9 ms, faster than 87.38% of Java online submissions for Group Anagrams. Memory Usage: 56.3 MB, less than 37.80% of Java online submissions for Group Anagrams.

class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        HashMap<String, List<String>> map = new HashMap<String, List<String>>();
        for (String str : strs) {
            char[] array = str.toCharArray();
            Arrays.sort(array);
            String key = new String(array); // 排序過的字符串
            List<String> list = map.getOrDefault(key, new ArrayList<String>());
            list.add(str);
            map.put(key, list);
        }
        return new ArrayList<List<String>>(map.values());
    }
}

Explanation (in my words)

  • How does their solution work?
    • 建立一個哈希表，儲存排序過的字串跟List
    • 遍歷字符串數組，比對如果有在哈希表內，就將哈希表的 value 添加一個List
  • What is the space/time complexity of their solution?
    • time: O(nlogn)
    • space: O(n)
