Runtime: 3 ms, faster than 20.90% of Java online submissions for Maximum Subarray. Memory Usage: 75.4 MB, less than 22.34% of Java online submissions for Maximum Subarray.

class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length;
        int sum = 0;
        int maxSum = Integer.MIN_VALUE;
        for (int i = 0; i < n; i++) {
            sum = Math.max(nums[i], nums[i] + sum);
            if (sum > maxSum) {
                maxSum = sum;
            }
        }
        return maxSum;
    }
}

class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length;
        if (n == 0) return 0;
        int sum = 0;
        int maxSum = Integer.MIN_VALUE;

        for (int i = 0; i < n; i++) {
            if (sum < 0) {
                sum = 0;
            }
            sum += nums[i];
            if (sum > maxSum) {
                maxSum = sum;
            } 
        }

        return maxSum;
    }
}

Solution #2 [DP]

Runtime: 2 ms, faster than 74.13% of Java online submissions for Maximum Subarray. Memory Usage: 74.6 MB, less than 37.91% of Java online submissions for Maximum Subarray.

class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length;
        int maxSum = Integer.MIN_VALUE;
        int[] dp = new int[n];
        for (int i = 0; i < n; i++) {
            if (i == 0) {
                dp[i] = nums[i]; 
            } else {
                dp[i] = Math.max(nums[i], nums[i] + dp[i-1]); 
            }
            if (dp[i] > maxSum) {
                maxSum = dp[i];
            } 
        }
        return maxSum;
    }
}

func maxSubArray(nums []int) int {
    dp, res := make([]int, len(nums)), nums[0]
    dp[0] = nums[0]
    for i := 1; i < len(nums); i++ {
        if dp[i-1] > 0 {
            dp[i] = dp[i-1] + nums[i]
        } else {
            dp[i] = nums[i]
        }
        if dp[i] > res {
            res = dp[i]
        }
    }
    return res
}

Explanation (in my words)

  • How does their solution work?
    • 以nums[i]為結尾的「最大子數和」為dp[i]
    • dp[i]有兩種選擇，與前面相鄰的子數組連接，形成一個更大的子數組；要馬不跟前面的子數組連接，自己作為一個子數組
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(n)

Solution #3 [DP優化空間]

Runtime: 2 ms, faster than 59.39% of Java online submissions for Maximum Subarray. Memory Usage: 75 MB, less than 25.20% of Java online submissions for Maximum Subarray.

class Solution {
    public int maxSubArray(int[] nums) {
        int n = nums.length;
        int maxSum = Integer.MIN_VALUE;
        int sum = 0;
        for (int i = 0; i < n; i++) {
            if (i == 0) {
                sum = nums[i]; 
            } else {
                sum = Math.max(nums[i], nums[i] + sum); 
            }
            if (sum > maxSum) {
                maxSum = sum;
            } 
        }
        return maxSum;
    }
}

  • How does their solution work?
    • 因為我們都是基於前一個dp[i-1]得出來的值，所以只需要一個變數就可以了

    • time: O(n)
    • space: O(1)
