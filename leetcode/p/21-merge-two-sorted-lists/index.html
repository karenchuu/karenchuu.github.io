21. Merge Two Sorted Lists

考過的公司：Asked by: Bytedance

Question

You are given the heads of two sorted linked lists list1 and list2.

Merge the two lists in a one sorted list. The list should be made by splicing together the nodes of the first two lists.

Return the head of the merged linked list.

Example 1:

Input: list1 = [1,2,4], list2 = [1,3,4]
Output: [1,1,2,3,4,4]

Example 2:

Input: list1 = [], list2 = []
Output: []

Example 3:

Input: list1 = [], list2 = [0]
Output: [0]

Constraints:

  • The number of nodes in both lists is in the range [0, 50].
  • 100 <= Node.val <= 100
  • Both list1 and list2 are sorted in non-decreasing order.

class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) {
            return list2;
          }
        if (list2 == null) {
            return list1;
        } 
        ListNode p1 = list1;
        ListNode p2 = list2;

        ListNode newHead = new ListNode(-1, null);
        ListNode tail = newHead;

        while (p1 != null && p2 != null) {
            if (p1.val <= p2.val) {
                ListNode tmp = p1.next;
                tail.next = p1; //  插入newHead尾節點
                tail = p1;
                tail.next = null;
                p1 = tmp; // 往後移動
            } else {                             
                ListNode tmp = p2.next;
                tail.next = p2; // 插入newHead尾節點
                        tail = p2;
                tail.next = null;
                p2 = tmp; // 往後移動             
            }
        }
        if (p1 == null) {
            tail.next = p2;
        } 
        if (p2 == null) {
                  tail.next = p1;
        }
        return newHead.next;
   }
}

Solution #2 [Recursive]

Runtime: 1 ms, faster than 77.14% of Java online submissions for Merge Two Sorted Lists.

Memory Usage: 43 MB, less than 57.34% of Java online submissions for Merge Two Sorted Lists.

class Solution {
    public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
        if (list1 == null) return list2;
        if (list2 == null) return list1;

        if (list1.val <= list2.val) {
            list1.next = mergeTwoLists(list1.next, list2);
            return list1;
        } else {
            list2.next = mergeTwoLists(list1, list2.next);
            return list2;
        }
    }
}

func mergeTwoLists(list1 *ListNode, list2 *ListNode) *ListNode {
    if list1 == nil {
        return list2
    }
    if list2 == nil {
        return list1
    }
    if list1.Val < list2.Val {
        list1.Next = mergeTwoLists(list1.Next, list2)
        return list1
    } else {
        list2.Next = mergeTwoLists(list1, list2.Next)
        return list2
    }
}
