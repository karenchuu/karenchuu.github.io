20. Valid Parentheses

Question

Given a string s containing just the characters '(', ')', '{', '}', '[' and ']', determine if the input string is valid.

An input string is valid if:

  1. Open brackets must be closed by the same type of brackets.
  2. Open brackets must be closed in the correct order.

Example 1:

Input: s = "()"
Output: true

Example 2:

Input: s = "()[]{}"
Output: true

Example 3:

Input: s = "(]"
Output: false

Constraints:

  • 1 <= s.length <= 104
  • s consists of parentheses only '()[]{}'.

✍🏽 My Solution

class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();
        for (char c : s.toCharArray()){
            if (c == '[' || c == '{' || c == '(') {
                stack.push(c);
            } else {
                if (stack.isEmpty()) return false;
                Character popC = stack.pop();
                if (c == ')' && popC != '(') return false;
                if (c == '}' && popC != '{') return false;
                if (c == ']' && popC != '[') return false;
            }
        }
        return stack.isEmpty();
    }
}

Solution #1 [王爭－連連消]

// 思路：連連消
// 如果棧是空的，就返回true
class Solution {
    public boolean isValid(String s) {
        Stack<Character> stack = new Stack<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);
            } else {
                if (stack.empty()) return false;
                char popC = stack.pop();
                if ( c == ')' && popC != '(') {
                    return false;
                }
                if ( c == ']' && popC != '[') {
                    return false;
                }
                if ( c == '}' && popC != '{') {
                    return false;
                }
            }
        }
        return stack.isEmpty();
    }
}

Explanation (in my words)

  • How does their solution work?
    • 連連消
    • 左括號一律入棧，右括號如果與棧頂元素匹配則出棧
    • 如果所有字符都處理完，檢查棧為空則回true，反之回false
    • if (stack.empty()) return false; 這句一直忘了寫
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(n)

Solution #2 [超簡短清晰-神！]

class Solution {
    public boolean isValid(String s) {
                Stack<Character> stack = new Stack<Character>();
                for (char c : s.toCharArray()) {
                        if (c == '(')
                            stack.push(')');
                        else if (c == '{')
                            stack.push('}');
                        else if (c == '[')
                            stack.push(']');
                        else if (stack.isEmpty() || stack.pop() != c)
                            return false;
                }
                return stack.isEmpty();
    }   
}

Explanation (in my words)

  • How does their solution work?
    • 遍歷字符串
    • 當字符為左、左大、左中括號，將右、右大、右中括號入棧
    • 當字符為右括號系列，比較stack為空，返回false；如果不等於stack.pop，返回false
    • 如果棧最後為空代表都將有效的左右括號消光了，若不為空，那么就是有不匹配的括號
  • What is the space/time complexity of their solution?
    • time: O(n)
    • space: O(n)
